EXERCÍCIO 01Iniciante

Selecionando notas com filter()

Dado o array, crie outro com as notas maiores ou iguais a 70.

● ● ●exercicio.jsJS
const notas = [55, 70, 82, 64];
⌁ Objetivo: selecionar, não transformar os valores.
↗
O que estamos observando?

Se a pessoa entende a condição e consegue aplicá-la — não apenas copiar a solução.

✳
Assistente · resposta direta

Para manter apenas as notas maiores ou iguais a 70, use filter() com uma comparação:

● ● ●solucao.jsJS
const aprovadas = notas.filter(nota => nota >= 70);
// [70, 82]

Esta opção resolve imediatamente. É útil quando a intenção é obter uma informação rápida.

1 Corrigir2 Aplicar sozinho
✳
Modo Aprender · etapa orientada

O filter() é uma boa escolha. Veja esta tentativa e descubra qual parte não está funcionando:

● ● ●minha-tentativa.js
A simulação analisa uma condição simples com função de seta; não executa o código digitado.

Muito bem. Agora um novo problema: no array [18, 25, 30, 22], selecione só as temperaturas menores que 25, sem incluir o 25.

● ● ●transferencia.js
Use uma função de seta no filter(). A checagem é didática e reconhece padrões simples.

O PROBLEMA OBSERVADO

Entender a explicação não garantiu acertar a próxima implementação.

Depois de uma atividade assistida sobre filter(), a primeira tentativa independente ainda confundiu o operador que cria funções (=>) com o operador de comparação (>=).

TRANSCRIÇÃO DO PÓS-TESTE (P04-B)pontuacoes.filter(pontuacoes => pontuacoes => 70)

Essa transcrição veio da resposta do participante neste estudo; não é uma captura de uma conversa na Lumina.

05 / SOBRE O PROJETO

Uma investigação individual.
Com apoio de IA, não substituída por ela.

Comecei com uma pergunta: a IA ajuda a aprender ou apenas facilita a conclusão de tarefas? Estruturei os testes com apoio do ChatGPT, utilizei a Lumina como ferramenta investigada e criei um agente para explorar a proposta na prática.

Explicações baseadas no conhecimento do modelo

Modelos de linguagem não permitem identificar automaticamente qual documento específico de treinamento originou cada frase. Nesse caso, uma interface responsável deve declarar a limitação em vez de inventar referências.

Na demonstração deste site, respostas e feedbacks são regras previamente escritas em JavaScript; não são gerados por modelo de IA.
