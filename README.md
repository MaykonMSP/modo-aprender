# Modo Aprender — Desafio Lumina Start

Website estático, responsivo, feito para complementar os cinco slides do projeto individual de Maykon Pereira.

## O que é

- **Demonstração interativa simulada** de duas formas de interação: resposta direta e Modo Aprender, com dicas e uma atividade de transferência.
- **Evidências reais** da Lumina fornecidas pelo participante, incluindo diagnóstico de erro, aplicação posterior correta e um pedido urgente.
- **Painel conceitual de fontes**, separando documentação consultada na preparação do site, leitura recomendada e conhecimento do modelo.
- **Contexto metodológico e limitações** claros.

A demonstração não se conecta aos modelos da Lumina, não é IA generativa e não executa o código digitado pelo visitante. A validação é uma checagem local simplificada por padrões de texto; não é um compilador JavaScript nem uma avaliação científica de aprendizagem.

## Como visualizar

Abra `index.html` no navegador. É recomendado manter a pasta `assets/` junto com os arquivos `styles.css` e `script.js`.

## Como publicar no GitHub Pages

1. No GitHub, crie um repositório público com nome `modo-aprender`.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (`index.html`, `styles.css`, `script.js`, `.nojekyll` e `assets/`). Não envie apenas o arquivo `.zip`.
3. Vá a `Settings` > `Pages`.
4. Em `Build and deployment`, escolha `Deploy from a branch`, branch `main`, pasta `/(root)` e salve.
5. Após a publicação, o endereço tende a seguir o formato `https://SEU-USUARIO.github.io/modo-aprender/`. Confirme a URL exata em `Settings` > `Pages` antes de utilizá-la no formulário.

Documentação oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
